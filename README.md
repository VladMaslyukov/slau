# Практическая работа № 1 — вариант 12

## Запуск

1. Откройте папку проекта в PyCharm.
2. Выберите Python 3.11 или 3.12 и виртуальное окружение `.venv`.
3. В терминале PyCharm выполните:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Запустите `main.py`.

## Результаты

Программа создаёт в папке `results` ровно шесть PNG-графиков, соответствующих рисункам 1–6 отчёта:

1. `01_relative_error_vs_rhs_perturbation.png` — относительная погрешность решения от относительного возмущения правой части.
2. `02_divergence_original_systems.png` — расходимость простых итераций и метода Зейделя для исходных систем.
3. `03_convergence_preconditioned_system1.png` — нормы погрешности и разности соседних приближений для системы 1 после предобусловливания.
4. `04_convergence_normal_system2.png` — нормы погрешности и разности соседних приближений для нормальной системы 2.
5. `05_false_convergence_normal_system1.png` — погрешность и разность соседних приближений метода Зейделя для нормальной системы 1 на 20 000 итерациях.
6. `06_iterations_vs_accuracy.png` — фактическое число итераций в зависимости от требуемой точности.
